# OpenGL GLUT 2D Basics

A beginner-friendly Computer Graphics project
using C++ and OpenGL GLUT.

## Features

- Draw Points
- Draw Lines
- Draw Triangles
- Draw Rectangles
- Draw Squares
- Draw Circles
- Draw Ellipses
- Draw Polygons
- Draw Connected Lines
- Draw Text
- 2D Translation
- 2D Rotation
- Basic Animation
- Keyboard Interaction
- Mouse Interaction

## Technologies

- C++
- OpenGL
- GLUT / freeglut

## Controls

| Key | Action |
|-----|--------|
| SPACE | Pause / Resume |
| R | Reset |
| ESC | Exit |
| Left Click | Pause / Resume |

## Requirements

- C++ Compiler
- OpenGL
- GLUT or freeglut
